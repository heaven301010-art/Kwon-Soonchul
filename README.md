# Kwon-Soonchul

## MDA 공통작전상황도 (`mda/`)

해양영역인식(MDA) 순환(수집·감시 → 융합 → 분석 → 공유 → 결심 → 조치 → 평가)을 한반도 주변 해역에서 모의하는 상황도입니다. 브라우저로 `mda/index.html`을 열면 바로 동작합니다(빌드 불필요).

- **센서 융합**: 우주(SAR·EO·RF 위성), 수상(AIS·함정 레이더·해안 CCTV), 수중(고정형 수중감시·소노부이·함정 소나), 항공(해상초계기·무인기), 지상(레이더 감시대) 탐지를 표적별 트랙으로 융합합니다. 12분 이상 탐지가 없으면 추적 소실로 바뀌고 추정 위치 오차 원이 커집니다.
- **화면 배치**: 해도 오른쪽의 '해양영역인식 종합 정보 현황' 상자에 선종별 보유 표적 수와 출처별(우주·항공·지상·수상·수중) 탐지 내역을 선종별로 모으고(상단 단추로 숨기기 가능), 오른쪽 열에 MDA 순환·이상징후·수집 요청·상황 일지·상황보고를 둡니다. 밝은 해도 테마입니다.
- **경계선**: NLL, KADIZ, EEZ(한·일 대륙붕 북부 경계와 미획정 중간선)를 개략으로 표시하고 켜고 끌 수 있습니다. MCA(KTO)는 `scenario.js`의 `mca`에 인가된 출처의 좌표를 넣으면 표시됩니다.
- **시나리오**: AIS 신호 소실 후 환적 의심(D301·D302), EEZ 침범 조업(C501), NLL 침범(H201), 수중 미식별 접촉(U402), KADIZ 진입 항공기(U403). 패널의 **조치 승인**을 누르면 함정 차단 기동, 위성 긴급 촬영, 무인기 재배치, 소노부이 부설이 실제로 수행되고 결과가 평가됩니다.
- **선종 색 구분**: 한국 해군·해경, 미국 해군, 북한 해군, 중국 해군·해경, 일본 해상자위대·해상보안청, 러시아 해군, 상선, 어선, 기타·조사선, 미식별을 색으로 구분하고 기호 모양은 식별 상태를 나타냅니다.
- **선박**: 남측 상선·어선·연안 여객선·해경 경비함과 북측 어선·화물선·경비정(대부분 AIS 미송출)을 가상으로 배치합니다.
- **배경 통항 선박**: 약 990척. 해수부 GICOMS(AIS·LRIT), 해경(V-PASS·VTS) 연계 자료를 흉내 내어 출처별로 집계합니다. 중립 선박은 작게 그리고 확대했을 때만 진행선을 보입니다.
- **해양 기반시설과 AI 이상항적**: 해저케이블·해상풍력 단지(개략)를 표시하고, 케이블 상공 저속 배회(L601)와 EEZ 안 격자형 조사 항적(R701)을 자동 탐지합니다.
- **기관 간 정보 공유**: 해수부(GICOMS)·해경·기상청·KIOST·국립해양조사원·해군 상황도·국가 MDA 플랫폼(K-IFC 가칭)·해외 IFC 사이의 정보 흐름도를 실시간 수치와 함께 보여 주고, 이상징후마다 공유 대상 기관을 표시합니다.
- **RF 위성 신호 정보**: RF 위성 군집이 수신한 방사원(항해·군용 레이더, VHF 무선)의 종류·주파수·위치 오차와 AIS 대조 결과를 보여 주고, AIS 미대조 신호는 암선 의심, 군용 레이더는 적성으로 분류합니다. 표적별 RF 신호 수집 요청도 할 수 있습니다.
- **정보 구분과 공유 범위**: 오경원 외(2024, 『KNST』 7(3))의 해양영역정보 구분에 따라 군사·기관·민간 정보와 비밀 취급 대상을 집계하고, IFC 방식으로 사건 유형과 협력국 공유 가능 여부를 표시합니다.
- **조작**: 센서 레이어를 눌러 끄고 켜기(끄면 해당 탐지가 융합에서 빠짐), 표적 클릭으로 상세 보기와 수집 요청(SAR 긴급 촬영·무인기·소노부이), 휠·드래그로 확대·이동, ×60/×180/×600 모의 속도.

파일 구성: `index.html`(화면·모의 로직), `scenario.js`(센서·표적·항로 배치), `land.js`(Natural Earth 1:10m 해안선 발췌, 퍼블릭 도메인).

해안선과 NLL은 개략이며, 모든 표적·센서 배치는 가상 훈련용 데이터입니다.
