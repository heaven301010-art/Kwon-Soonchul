# Kwon-Soonchul

## MDA 공통작전상황도 (`mda/`)

해양영역인식(MDA) 순환(수집·감시 → 융합 → 분석 → 공유 → 결심 → 조치 → 평가)을 한반도 주변 해역에서 모의하는 상황도입니다. 브라우저로 `mda/index.html`을 열면 바로 동작합니다(빌드 불필요).

- **센서 융합**: 우주(SAR·EO·RF 위성), 수상(AIS·함정 레이더·해안 CCTV), 수중(고정형 수중감시·소노부이·함정 소나), 항공(해상초계기·무인기), 지상(레이더 감시대) 탐지를 표적별 트랙으로 융합합니다. 12분 이상 탐지가 없으면 추적 소실로 바뀌고 추정 위치 오차 원이 커집니다.
- **화면 배치**: 해도 오른쪽의 '해양영역인식 종합 정보 현황' 상자에 선종별 보유 표적 수와 출처별(우주·항공·지상·수상·수중) 탐지 내역을 선종별로 모으고(상단 단추로 숨기기 가능), 오른쪽 열에 MDA 순환·이상징후·수집 요청·상황 일지·상황보고를 둡니다. 밝은 해도 테마입니다.
- **경계선**: NLL, KADIZ, EEZ(한·일 대륙붕 북부 경계와 미획정 중간선)를 개략으로 표시하고 켜고 끌 수 있습니다. MCA(KTO)는 `scenario.js`의 `mca`에 인가된 출처의 좌표를 넣으면 표시됩니다.
- **시나리오**: AIS 신호 소실 후 환적 의심(D301·D302), EEZ 침범 조업(C501), NLL 침범(H201), 수중 미식별 접촉(U402), KADIZ 진입 항공기(U403), 해저케이블 상공 배회(L601), 무단 해양과학조사(R701), 중국 연계 그림자선단(SF91~94, AIS 위치 위장·환적), 대화퇴(동해퇴) 부근 중·러 연합해상훈련 단대(CN21·CN22·RU43·RU44), 서해 북부 위성통신 재밍. 해도는 대화퇴가 들어오도록 동경 136°까지 넓혔습니다. 패널의 **조치 승인**을 누르면 함정 차단 기동, 위성 긴급 촬영, 무인기 재배치, 소노부이 부설이 실제로 수행되고 결과가 평가됩니다.
- **긴급대응표적·관심표적**: 종합 정보 현황 상단에 긴급대응표적(적성)과 관심표적(미식별·의심)을 따로 모아 표적별 선종, 해역, 속력·침로, 최근접 아군 함정 거리, 탐지 출처, 경과 시간, 대응 상태(결심 대기·조치 중·평가 완료) 또는 식별 조치 권고를 보여 줍니다. 항목을 누르면 해당 표적이 선택됩니다.
- **선종 색 구분**: 한국 해군·해경, 미국 해군, 북한 해군, 중국 해군·해경, 일본 해상자위대·해상보안청, 러시아 해군, 상선, 그림자선단, 어선, 기타·조사선, 미식별을 색으로 구분하고 기호 모양은 식별 상태를 나타냅니다.
- **선박**: 남측 상선·어선·연안 여객선·해경 경비함과 북측 어선·화물선·경비정(대부분 AIS 미송출)을 가상으로 배치합니다.
- **배경 통항 선박**: 약 990척. 해수부 GICOMS(AIS·LRIT), 해경(V-PASS·VTS) 연계 자료를 흉내 내어 출처별로 집계합니다. 중립 선박은 작게 그리고 확대했을 때만 진행선을 보입니다.
- **해양 기반시설과 AI 이상항적**: 해저케이블·해상풍력 단지(개략)를 표시하고, 케이블 상공 저속 배회(L601)와 EEZ 안 격자형 조사 항적(R701)을 자동 탐지합니다.
- **기관 간 정보 공유**: 해수부(GICOMS)·해경·기상청·KIOST·국립해양조사원·해군 상황도·국가 MDA 플랫폼(K-IFC 가칭)·해외 IFC 사이의 정보 흐름도를 실시간 수치와 함께 보여 주고, 이상징후마다 공유 대상 기관을 표시합니다.
- **위성**: 임무별로 SAR(주야간·전천후), EO/IR(전정색 주간·적외선 주야간), 다분광(Sentinel-2·Landsat·차세대중형위성 4호·PlanetScope, 천리안 2B호 GOCI-II 해색), 초분광(PRISMA·EnMAP·Pixxel·Wyvern, 유막·물질 판별), RF(HawkEye 360·Unseenlabs)로 나눕니다. 태양동기·경사 궤도 위성 53기(아리랑, 군 정찰위성, 차세대중형위성, Sentinel, Landsat, RCM, 정보수집위성, ICEYE, Capella, WorldView Legion, 주변국 정찰위성 등)를 원궤도 근사로 이동시키고, 정지궤도 7기와 저궤도 통신 위성군(Starlink·OneWeb·Iridium 표본 646기)을 표시합니다. 광학 계열은 주간에만, 적외선 모드는 야간에도 탐지하며 해상도 30m보다 거친 센서는 선박 탐지에 쓰지 않습니다. 궤도요소·촬영 모드 제원은 개략값, 위상은 가상입니다.
- **우군 위성통신**: 함정별 통신 링크(아나시스 2호·무궁화 5A·Starlink·OneWeb·Inmarsat·HF), 전송 속도, 지연, 손실률, 상태를 보여 주며, 서해 북부 재밍 시나리오에서 저궤도 우회와 RF 위성 재밍원 탐지를 모의합니다.
- **전자기스펙트럼 영향성 평가**: GNSS, 위성통신, AIS, 해상 VHF, 레이더, 전술데이터링크, HF별 영향 범위, 영향 받는 우군·민간 수, 평가 등급(정상·주의·경계·심각), 대응을 집계합니다. 서해 북부 GPS 전파교란 시나리오에서는 영향권 선박의 AIS·V-PASS 위치가 어긋나고, 레이더 위치와의 불일치로 교란을 탐지해 항행경보와 관성항법·eLoran 전환을 모의합니다.
- **RF 위성 신호 정보**: RF 위성 군집이 수신한 방사원(항해·군용 레이더, VHF 무선)의 종류·주파수·위치 오차와 AIS 대조 결과를 보여 주고, AIS 미대조 신호는 암선 의심, 군용 레이더는 적성으로 분류합니다. 표적별 RF 신호 수집 요청도 할 수 있습니다.
- **정보 구분과 공유 범위**: 오경원 외(2024, 『KNST』 7(3))의 해양영역정보 구분에 따라 군사·기관·민간 정보와 비밀 취급 대상을 집계하고, IFC 방식으로 사건 유형과 협력국 공유 가능 여부를 표시합니다.
- **수집 요청**: 관측 해역(표적 주변·주요 해역·좌표 입력·지도 지정), 관측폭, 요구 해상도, 수집 시한, 우선순위, 목적을 입력하면 위성(SAR·EO·RF 위성 모드별 해상도·관측폭), 항공(해상초계기·무인기), 해상(아군 함정·해경 경비함·연합 함정), 지상(해안 레이더·VTS·항만 CCTV), 수중(고정형 수중감시·소노부이) 전 가용 센서의 가용 시각과 적합·부분(관측폭 부족 분할 횟수)·불가(해상도 미달·시한 내 접근 불가·광학 야간) 판정을 보여 줍니다. 센서별로 요청하거나 영역별 최적 센서를 자동 요청할 수 있고, 요청 해역은 지도에 표시되며 수행 결과(촬영 표적 수 등)가 요청 현황에 기록됩니다.
- **극지(북극) MDA**: 상단 `북극항로` 단추로 북극점 중심 투영 상황도를 엽니다. 북극해항로(NSR)·북서항로(NWP)·북극점 횡단항로(TSR, 장래)와 10월 해빙 가장자리(개략), 주요 항구·해협·군 기지를 표시하고, 한국·러시아·중국·미국·캐나다·노르웨이 선박 21척(가상 포함)을 위성 AIS와 극궤도 SAR·EO·RF 위성 통과 시 위치 확인으로 추적합니다. 빙급(Arc7·Arc4·PC)에 따른 결빙 해역 속력 저하, 정지궤도 통신 한계(약 75°N), 북극권 상공 위성 수를 보여 주며, 결빙 정체 시 쇄빙선 호송, AIS 보고 공백 시 극궤도 SAR 촬영, 러시아 북방함대 훈련구역 항행경보 공유 시나리오를 모의합니다.
- **조작**: 센서 레이어를 눌러 끄고 켜기(끄면 해당 탐지가 융합에서 빠짐), 표적 클릭으로 상세 보기와 수집 요청(SAR 긴급 촬영·무인기·소노부이), 휠·드래그로 확대·이동, ×60/×180/×600 모의 속도.

파일 구성: `index.html`(화면·모의 로직), `scenario.js`(센서·표적·항로 배치), `land.js`(Natural Earth 1:10m 해안선 발췌, 퍼블릭 도메인), `arcticland.js`(북위 27° 이북 Natural Earth 해안선 단순화본).

해안선과 NLL은 개략이며, 모든 표적·센서 배치는 가상 훈련용 데이터입니다.
