# Kwon-Soonchul

## MDA 공통작전상황도 (`mda/`)

해양영역인식(MDA) 순환(수집·감시 → 융합 → 분석 → 공유 → 결심 → 조치 → 평가)을 한반도 주변 해역에서 모의하는 상황도입니다. 브라우저로 `mda/index.html`을 열면 바로 동작합니다(빌드 불필요).

- **센서 융합**: 우주(SAR·EO·RF 위성), 수상(AIS·함정 레이더·해안 CCTV), 수중(고정형 수중감시·소노부이·함정 소나), 항공(해상초계기·UAV), 지상(레이더 감시대) 탐지를 표적별 트랙으로 융합합니다. 12분 이상 탐지가 없으면 추적 소실로 바뀌고 추정 위치 오차 원이 커집니다.
- **화면 배치**: 해도 오른쪽의 '해양영역인식 종합 정보 현황' 상자에 선종별 보유 표적 수와 출처별(우주·항공·지상·수상·수중) 탐지 내역을 선종별로 모으고(상단 단추로 숨기기 가능), 오른쪽 열에 MDA 순환·이상징후·수집 요청·상황 일지·상황보고를 둡니다. 밝은 해도 테마입니다.
- **경계선**: NLL, 지상 군사분계선(MDL), KADIZ, EEZ(한·일 대륙붕 북부 경계와 미획정 중간선)를 개략으로 표시하고 켜고 끌 수 있습니다. MCA(KTO)는 `scenario.js`의 `mca`에 인가된 출처의 좌표를 넣으면 표시됩니다. 지도의 표적 심볼은 `index.html`의 `SYMK`(기본 0.8) 배율로 크기를 조정합니다.
- **시나리오**: AIS 신호 소실 후 환적 의심(D301·D302), EEZ 침범 조업(C501), NLL 침범(H201), 수중 미식별 접촉(U402), KADIZ 진입 항공기(U403), 해저케이블 상공 배회(L601), 무단 해양과학조사(R701), 중국 연계 그림자선단(SF91~94, AIS 위치 위장·환적), 대화퇴(동해퇴) 부근 중·러 연합해상훈련 단대(CN21·CN22·RU43·RU44), 서해 북부 위성통신 재밍. 해도는 대화퇴가 들어오도록 동경 136°까지 넓혔습니다. 패널의 **조치 승인**을 누르면 함정 차단 기동, 위성 긴급 촬영, UAV 재배치, 소노부이 부설이 실제로 수행되고 결과가 평가됩니다.
- **긴급대응표적·관심표적**: 종합 정보 현황 상단에 긴급대응표적(적성)과 관심표적(미식별·의심)을 따로 모아 표적별 선종, 해역, 속력·침로, 최근접 아군 함정 거리, 탐지 출처, 경과 시간, 대응 상태(결심 대기·조치 중·평가 완료) 또는 식별 조치 권고를 보여 줍니다. 항목을 누르면 해당 표적이 선택됩니다.
- **해역별 확대 (동해·서해·남해)**: 한반도 해역 화면의 `전체 · 동해 · 서해 · 남해` 단추로 동해(포항 이북), 서해(태안 이북), 남해(제주도 포함 그 외 남해 전 해역)를 크게 보고, 확대 시 0.5° 보조 격자와 중립 선박 번호까지 표시합니다. 종합 정보 현황 맨 위에 해당 해역의 추적·적성·미식별 수, 육·해군 책임 구분, 선종별 수, 아군 함정, 해군 R/S·육군 감시대, 진행 중 이상징후, 주요 표적을 보여 줍니다.
- **선종 색 구분**: 한국 해군·해경, 미국 해군, 북한 해군, 중국 해군·해경, 일본 해상자위대·해상보안청, 러시아 해군, 상선, 그림자선단, 어선, 기타·조사선, 미식별을 색으로 구분하고 기호 모양은 식별 상태를 나타냅니다.
- **선박**: 남측 상선·어선·연안 여객선·해경 경비함과 북측 어선·화물선·경비정(대부분 AIS 미송출)을 가상으로 배치합니다.
- **배경 통항 선박**: 약 990척. 해수부 GICOMS(AIS·LRIT), 해경(V-PASS·VTS) 연계 자료를 흉내 내어 출처별로 집계합니다. 중립 선박은 작게 그리고 확대했을 때만 진행선을 보입니다.
- **해안 레이더**: 해군 R/S 11개소(저진·기사문·울진·울릉도·포항·욕지도·추자도·안마도·연평도·소청도·백령도, 탐지 40해리)와 육군 해안 감시대 13개소(탐지 12해리)를 구분해 표시하고 탐지·융합에 반영합니다. 우리 해안선(도서 포함)에서 12해리 안쪽은 육군, 바깥은 해군이 감시 책임을 지며, 12해리 띠를 지도에 표시하고 표적이 경계를 넘으면(3분 연속 확인) 인계인수를 기록·집계합니다.
- **통합 극지정보체계**: 북극항로 해도에서 오른쪽 칸에 극지연구소·기상청·해양수산부·국립해양조사원·한국해양수산개발원과 코페르니쿠스 CDSE·우리 극궤도 위성·국제 협력 정보가 통합 체계로 흘러드는 흐름도와 북극 해상·수중·항공·우주 정보를 표시합니다. 코페르니쿠스 CDSE 카탈로그(OData 공개 검색 API)에서 선택한 항로 해역의 최근 3일 Sentinel-1·2·3 영상 목록을 브라우저에서 직접 조회하고, 외부 접속이 막힌 환경에서는 시뮬레이션 궤도 기반 모의 목록으로 표시합니다(영상 내려받기는 CDSE 무료 회원 로그인 필요).
- **관심해역 해양정보 통합체계**: 원해 SLOC 화면 오른쪽에 해양수산부·외교부·합참/해군작전사·한국해양수산개발원·선사와 UKMTO·MSCHOA·CMF/IMSC·IFC-IOR/싱가포르 IFC·코페르니쿠스 CDSE 정보가 통합체계로 모여 청해부대·우리 선박으로 전파되는 흐름도, 원해 해상·수중·항공·우주 정보, 선택 해역의 CDSE Sentinel 영상 조회를 표시합니다.
- **해상초계기 대잠 초계 패턴**: 해상초계기는 육지와 NLL 이북을 피해 바다 위로만 비행합니다(서해·남해·동해 연안 바깥 해상 경유점으로 우회). 평시에는 동해 NLL 남쪽→남해→서해 NLL 남쪽→남해 초계 구역을 돌며 동서 방향 평행 탐색, 남북 방향 평행 탐색, 지그재그 탐색, 확장 사각 탐색 패턴을 번갈아 비행하고, 대잠 탐색 임무를 받으면 기준점 둘레에서 확장 사각 탐색부터 실시합니다. 지도에 남은 비행 경로를 표시하고, 현재 패턴 이름은 항공정보 칸 임무에 나옵니다.
- **유무인복합전투체계**: UAV-1(서해), UAV-2(남해 상시 해상 초계, 4가지 탐색 패턴 순환)과 USV-1(서해 NLL, 모함 F108 통제)·USV-2(동해 NLL, 모함 F101 통제)가 NLL을 따라 좌우로 왕복 경비합니다. USV는 수상정보 출처(USV)로 탐지·융합에 반영되고, 종합 정보 현황의 '유무인복합전투체계 운용현황'에 유인(해상초계기·해상작전헬기)·무인(UAV·USV) 자산별 위치·임무·탐지 표적 수·통제·데이터링크 상태(재밍 영향 시 저하)를 표시합니다.
- **연안 순찰 함정**: 연안초계함(OPV) 4척, PKX 검독수리 고속정 5척, PKG 유도탄고속함 3척이 서해 NLL 남측(백령도·연평도), 서해 중부·남부, 남해 서부·동부, 제주, 동해 NLL 남측·근해(고성~거진, NLL 남측 외해), 동해 중부·남부 연안의 순찰 경로(점선)를 왕복합니다. 함종별 탐지 반경(PKX 22km, PKG 30km, OPV 35km)으로 수상 탐지에 반영되고, 해역 감시 요청에 투입되면 임무 후 순찰 경로로 복귀합니다(`scenario.js`의 `coastal`).
- **선택 표적 팝업**: 한반도 해역에서 표적 기호를 누르면 선택 표적 정보(선종·위치·탐지 출처·RF·통신 등)와 수집 요청 단추가 누른 지점 옆에 팝업으로 뜹니다. 오른쪽 정보칸을 가리지 않는 쪽에 놓이며, `✕ 닫기` 단추나 Esc 키로 닫습니다. 목록에서 표적을 고르면 지도 왼쪽 위에, 휴대폰 화면에서는 아래쪽에 뜹니다.
- **기동부대 대치 (가상)**: 제주 해군기지를 모기지로 하는 한국형 유무인전력항모(CVX)·이지스 구축함 2·호위함 2·군수지원함과 함재 UAV 2·USV 2로 이루어진 기동부대를 두고, 서해 한·중 잠정조치수역(개략)에 중국 랴오닝 항모전단(055·052D×2·054A·901, 중국 UAV 2·USV 2)이 진입하면 지휘결심 지원체계에 경보가 뜹니다. 조치 승인 시 기동부대가 제주에서 출동해 제주 남서쪽을 돌아 서해로 북상 전개하며, 이동 중에도 함재 UAV·USV가 편대 앞에서 먼저 운용되고 함재 UAV는 먼저 날아가 전방 감시선을 형성합니다. 양측 모두 무인전력은 편대 앞, 유인함정은 뒤에 배치되며 서로 마주 보도록 대치합니다. 유무인복합전투체계 운용현황에 CVX를 통제함으로 표시하고, '기동부대 현황'에 부대 상태(제주 기지 대기·제주 출동/서해 전개 이동·대치 감시, 도착 예정 시각), 위치·속력·정면 방위, 무인 전방 감시 거리, 랴오닝함까지 거리, 함정·전력별 역할·위치·CVX 거리를 보여 줍니다. 해군 함정·항공기·UAV·USV는 남색 테두리 원 안에 크게 표시해 다른 표적과 구분합니다(CVX는 갑판 모양, 무인전력은 점선 테두리).
- **데이터 전송 상태**: 유무인복합전투체계 운용현황에 자산별 데이터링크 종류(Link-16·함-헬기 데이터링크·C밴드 LOS·위성 중계 등), 전송률, 지연, 손실률과 상태(정상·주의·재밍 저하)를 표시합니다.
- **원해 거점항만 무인전력·청해부대**: 원해 SLOC 화면에 한국 활용 거점항만(푸자이라·지부티)과 배치 UAV·USV를 표시하고, 정기 기동탐색(4가지 패턴, 해상 경로)과 이상징후 카드의 대응 출동(현장 감시 90분 후 복귀), 데이터링크·연료 상태를 보여 줍니다. 아덴만 청해부대(CH2)는 IRTC 선단 호송 기동을 하며 유류·청수·부식 소모와 살랄라 보급, 무장·기관·장비 상태를 현황 칸에 표시합니다.
- **해상작전헬기·대잠 정보**: 대형 경비함정(F101·F109 AW-159, F105 링스)이 하루 1~2회 1시간 내외 초계비행을 하며 레이더·EO/IR로 수상 표적을 탐지·식별하고 디핑소나로 대잠 탐색을 합니다(수중 접촉 시 추정 위치 부근 디핑). 종합 정보 현황의 '대잠 정보 현황'에 수중 접촉(상태·추정 오차·최근접 대잠 자산), 대잠 자산(고정형·소노부이·초계기·헬기·함정 소나), 수중 음향 환경을 표시합니다.
- **해양 기반시설과 AI 이상항적**: 해저케이블·해상풍력 단지(개략)를 표시하고, 케이블 상공 저속 배회(L601)와 EEZ 안 격자형 조사 항적(R701)을 자동 탐지합니다.
- **해양정보 공유상황도**: 해수부(GICOMS)·해경·기상청·KIOST·국립해양조사원·해군 상황도·국가 MDA 플랫폼(K-IFC 가칭)·해외 IFC 사이의 정보 흐름도를 실시간 수치와 함께 보여 주고, 이상징후마다 공유 대상 기관을 표시합니다.
- **위성**: 임무별로 SAR(주야간·전천후), EO/IR(전정색 주간·적외선 주야간), 다분광(Sentinel-2·Landsat·차세대중형위성 4호·PlanetScope, 천리안 2B호 GOCI-II 해색), 초분광(PRISMA·EnMAP·Pixxel·Wyvern, 유막·물질 판별), RF(HawkEye 360·Unseenlabs)로 나눕니다. 태양동기·경사 궤도 위성 53기(아리랑, 군 정찰위성, 차세대중형위성, Sentinel, Landsat, RCM, 정보수집위성, ICEYE, Capella, WorldView Legion, 주변국 정찰위성 등)를 원궤도 근사로 이동시키고, 정지궤도 7기와 저궤도 통신 위성군(Starlink·OneWeb·Iridium 표본 646기)을 표시합니다. 광학 계열은 주간에만, 적외선 모드는 야간에도 탐지하며 해상도 30m보다 거친 센서는 선박 탐지에 쓰지 않습니다. 궤도요소·촬영 모드 제원은 개략값, 위상은 가상입니다.
- **우군 위성통신**: 함정별 통신 링크(아나시스 2호·무궁화 5A·Starlink·OneWeb·Inmarsat·HF), 전송 속도, 지연, 손실률, 상태를 보여 주며, 서해 북부 재밍 시나리오에서 저궤도 우회와 RF 위성 재밍원 탐지를 모의합니다.
