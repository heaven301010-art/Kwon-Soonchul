# 기관 로고 파일

이 폴더에 기관 로고 이미지를 아래 이름으로 올리면, 해양정보 공유상황도·통합 극지정보체계·관심해역 해양정보 통합체계 흐름도의 해당 기관 상자 왼쪽 위에 자동으로 표시됩니다.

- 형식: `.png` 또는 `.svg` (정사각형에 가까운 작은 그림 권장, 예: 128×128 px, 배경 투명)
- 파일이 없는 기관은 로고 없이 그대로 표시됩니다.
- 사용 허락을 받았거나 사용해도 되는 로고만 올려 주세요.

| 파일 이름 | 기관 (흐름도 상자) |
|---|---|
| `gov` | 정부상징: 해양수산부·기상청·외교부 (정부기관은 하나로 통일) |
| `kcg` | 해양경찰청 엠블럼 |
| `khoa` | 국립해양조사원 엠블럼 |
| `kiost` | KIOST·KHOA (한국해양과학기술원) |
| `kopri` | 극지연구소 |
| `kmi` | 한국해양수산개발원 |
| `navy` | 해군 MDA 상황도 / 청해부대·해군 MDA |
| `jcs` | 합참·해군작전사 |
| `ksa` | 선사·해운협회 (한국해운협회) |
| `copernicus` | 코페르니쿠스 CDSE |
| `ukmto` | UKMTO·MSCHOA |
| `cmf` | CMF·IMSC (바레인) |
| `ifc` | 해외 정보융합센터(IFC) (공유상황도·원해 SLOC) |
| `sat` | 국가-군 극궤도 위성 (SAR 위성 그림) |

예: 극지연구소 로고는 `kopri.png`, 한국해양수산개발원 로고는 `kmi.svg`
